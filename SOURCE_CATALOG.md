# Source catalog

This is a research map, not a bibliography or clearance record. “Can settle” means the evidence can materially constrain a claim when provenance, dating and context are sound; it never means a single source is sufficient. Episode numbers match the file names in the [episode index](README.md).

## Use protocol

For every substantive claim, the episode claim sheet records source ID, precise citation, provenance, date, language, translation, evidentiary role, counterevidence, confidence and rights status. Sources from different classes should be triangulated where possible. Absence of convergence must appear in the script rather than being edited away.
